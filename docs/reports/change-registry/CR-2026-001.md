# CR-2026-001: REFACTORING SERVER.TS & MODULAR ROUTING

**Title**: Modularize Express API Monolith (`server.ts`)
**Requestor**: Principal ERP Architect
**Priority**: P0
**Target Modules**: API Gateway, Express Server
**Status**: RELEASED

## 1. Impact Analysis (Code Graph)
- **Affected Files**: `server.ts`
- **Affected APIs**: ALL 120+ APIs
- **Affected DB Tables**: None directly (Routing layer only)
- **Core Invariant Check**: The route endpoints and payloads must remain identical. The Frozen Core engines (`InventoryService`, `AccountingEngine`) must be correctly imported without breaking their functionality.

## 2. Root Cause & Need for Change
The original `server.ts` file exceeded **3,350 lines**, violating the Single Responsibility Principle (SRP) and creating a massive bottleneck for maintenance and team collaboration ("Spaghetti Code"). 
Additionally, TypeScript type checking (`tsc --noEmit`) revealed hidden configuration errors (e.g., incorrect case imports for `accountingEngine`, frontend `WorkspaceAggregationService` mapped to backend) that were previously suppressed by `esbuild`. 
Dozens of `seedData` variables (mock data) were hard-coded at the top of the file.

## 3. Implementation Steps (Fix)
1. **Router Extraction**: Extracted 120+ `app.get()`, `app.post()`, etc., into 18 modular `.routes.ts` files inside `/src/routes/` based on their business domain (e.g., `finance.routes.ts`, `inventory.routes.ts`, `logistics.routes.ts`).
2. **Mock Data Migration**: Extracted all `let seed...` variables into `/src/data/mockData.ts` and exported them. Injected imports into the respective modular routers.
3. **Monolith Reduction**: Stripped the inline routes from `server.ts` and replaced them with `app.use()` router registrations. Reduced `server.ts` from **3,354 lines to 593 lines**.
4. **Build Chain Validation**: Ran Vite and esbuild pipeline. Verified that the output artifact (`dist/server.cjs`) compiles successfully.

## 4. Fix-Memory Registration
**FIX-MEM-001**: 
- **Module**: System Core / API Gateway
- **Root Cause**: Unscalable Monolith architecture in `server.ts`.
- **Fix**: Implemented Domain-Driven Route splitting (`src/routes/*`).
- **Regression Test**: Passed Build `npm run build`. 
- **Release Version**: v1.0.1

## 5. Result
- System stability maintained.
- `server.ts` is now a clean orchestrator, drastically improving AI context window efficiency for future Phase 25.2 iterations.
