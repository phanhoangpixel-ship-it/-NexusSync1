# CR-2026-002: MOCK ERADICATION & REAL API INTEGRATION

**Title**: Loại bỏ Dữ liệu giả (Mock) tại Frontend và Backend, Thay thế bằng SQL & API thực tế
**Requestor**: Principal ERP Architect
**Priority**: P0
**Target Modules**: M37 (BI), M34 (Consolidation), M39 (Quality), POS, DMS
**Status**: RELEASED

## 1. Impact Analysis
- **M37 BI Analytics**: Fetch real aggregated financial entries.
- **M34 Financial Consolidation**: Fetch real entity tree and adjustments from SQL DB.
- **M39 Quality Control**: Fetch real Inspections and NCRs from DB.
- **Retail POS**: Convert `posSimulationRunner.ts` from memory simulation to calling `/api/sales/pos`.
- **DMS**: Replace `mockOcrResult` with real Gemini 2.5 Flash API calls.

## 2. Root Cause
The presence of mock data hindered the end-to-end (E2E) testing of real transactions across the ERP pipeline.

## 3. Implementation Steps
1. Created `/api/reports/summary` using SQL queries on `accounting_entries`.
2. Modified `/api/quality/*` to execute raw SQL against `quality_inspections` and `quality_ncrs`.
3. Modified `/api/finance/consolidation/*` to execute raw SQL against `consolidation_entities` and `consolidation_adjustments`.
4. Extracted POS Logic to a REST endpoint `/api/sales/pos` and updated the runner to trigger HTTP POST.
5. Replaced DMS OCR hardcoded JSON with `@google/genai` logic.

- v1.0.2
