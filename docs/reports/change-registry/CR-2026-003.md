# CR-2026-003: Củng cố Authorization & State Workflow

**Title**: Triển khai JWT Middleware & Hoàn thiện Approval History Workflow
**Requestor**: Principal ERP Architect
**Priority**: P0
**Target Modules**: API Gateway, Core System, Workflow Engine
**Status**: RELEASED

## 1. Impact Analysis
- **API Security**: Toàn bộ các API routes trong hệ thống hiện tại (hơn 120+ APIs) đều được bảo vệ bởi middleware xác thực JWT.
- **Frontend Core**: Đã áp dụng Monkey-patching an toàn trên toàn hệ thống trong `main.tsx` để tự động tích hợp Bearer token vào HTTP Headers cho toàn bộ request `fetch()`, tránh việc phải can thiệp sửa đổi trên 120 API calls cũ gây rủi ro đứt gãy.
- **State Workflow**: Bổ sung bảng `approval_history` vào Schema của Drizzle ORM để lưu vết (audit log) quy trình xét duyệt của tài liệu từ lúc khởi tạo đến khi đóng vòng đời.

## 2. Root Cause
- Hệ thống trước đây chỉ dùng "Simulated Login" (chuyền dữ liệu vai trò bằng plaintext trong body hoặc query string) gây ra lỗ hổng bảo mật nghiêm trọng nếu triển khai thực tế (PH23-001).
- Workflow thiếu tính minh bạch vì hệ thống xét duyệt chưa có công cụ lưu lịch sử chuyển đổi trạng thái của tài liệu (Approval Log/History).

## 3. Implementation Steps (Fix)
1. Cài đặt `jsonwebtoken` và các type definitions tương ứng.
2. Viết mới file `src/middleware/auth.middleware.ts` sử dụng chuẩn Bearer Token để chặn mọi route truy cập `/api/*` không hợp lệ (ngoại trừ whitelist `/api/auth/login`).
3. Sửa đổi `src/routes/auth.routes.ts` để API login trả về một valid token đã được signed bằng JWT Secret thay vì chuỗi hardcode cũ.
4. Cập nhật `SimulatedLoginModal.tsx` để mỗi lần đổi vai trò sẽ trigger HTTP Request lên server để cấp mới JWT Token và lưu vào `localStorage`.
5. Tạo HTTP Interceptor toàn cục qua Monkey-patching `window.fetch` tại `src/main.tsx` tự động gắn `Authorization` header vào mọi request gửi đi.
6. Thiết kế bổ sung bảng `approval_history` tại `db/schema.ts` theo tiêu chuẩn Drizzle SQLite, cung cấp trường `action`, `step`, và `comments` lưu giữ audit cho Workflow.
