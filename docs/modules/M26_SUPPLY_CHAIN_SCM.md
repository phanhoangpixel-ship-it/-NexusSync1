## 1. Executive Summary & Purpose
M26 orchestrates enterprise-wide demand forecasting, Master Production Scheduling (MPS), and multi-level Material Requirements Planning (MRP) netting. It bridges commercial commitments from Sales Orders (M13) with production capacity in MES (M25) and procurement workflows in P2P (M08), ensuring optimal inventory levels, zero uncoordinated stockouts, and verifiable supply chain pegging traceability.

---

## 2. Domain Authority & Single-Writer Boundaries

In strict compliance with NexusSync ERP Architecture Rules (Rule 03 - Rule 07):

| Domain Entity | Responsible Authority | M26 Relationship & Boundary Rule |
| :--- | :--- | :--- |
| **Purchase Orders (`purchase_orders`)** | **M08 Purchase Authority** | **Strict Non-Authority:** M26 only writes to `purchase_requisitions`. Conversion to official PO delegates exclusively via `POST /api/purchase-orders`. Zero direct mutations to `purchase_orders`. |
| **Manufacturing Orders (`manufacturing_orders`)** | **M25 MES Authority** | **Strict Non-Authority:** M26 generates MO suggestions in `mrp_results`. Conversion to official MO delegates exclusively via `POST /api/manufacturing/work-orders` or `POST /api/manufacturing/orders/from-mrp`. Zero direct mutations to `manufacturing_orders`. |
| **Inventory Balances (`stock_balances`)** | **M17 Inventory Authority** | **Read-Only:** On-hand and reserved stocks are queried strictly from M17 balances. Zero direct stock movements or manual ledger entries. |
| **Standard / Actual Costing** | **M42 Costing Authority** | **Read-Only:** Material costs for PR estimations are retrieved from master data and M42 without altering cost layers. |
| **Audit Logs (`audit_logs`)** | **M02 Audit Authority** | All 6 MRP lifecycle events logged via `AuditService.recordAuditLog()`. |
| **Archival Dossiers (`dms_documents`)**| **M29 DMS Authority** | MRP run snapshots cryptographically hashed (SHA-256) and archived into M29 DMS. |

## 3. Data Contracts & Database Schema

1. `scm_forecasts`: Statistical demand forecasts with methods (`EXPONENTIAL_SMOOTHING`, `HOLT_WINTERS`, `MOVING_AVERAGE`), confidence level, MAE, and MAPE accuracy metrics.
2. `mps_schedules`: Master Production Schedules tracking Period Start/End, Forecast Demand, Sales Order Demand, Projected Available Balance (PAB), and Available-To-Promise (ATP).
3. `mrp_runs`: Historical immutable MRP execution logs (`run_code`, `run_type`: `regenerative` vs `net-change`, horizon days, products analyzed, gross/net requirements, execution duration, parameters JSON).
4. `mrp_results`: Line-by-line MRP netting outcomes (SKU, low-level code, gross requirement, scheduled receipts, on-hand, reserved, safety stock, net requirement, planned order receipt/release, suggested action: `CREATE_PR`, `CREATE_MO`, `NONE`).
5. `mrp_exceptions`: Supply chain exception messages categorized by severity (`CRITICAL_STOCKOUT`, `LEAD_TIME_VIOLATION`, `EXCESS_INVENTORY`, `PAST_DUE_ORDER`, `NO_BOM_FOUND`).
6. `purchase_requisitions`: Planned purchase suggestions generated by MRP with delegation link (`delegated_po_id`, `delegated_po_code`, `delegated_at`, `status`).

## 4. REST API Suite

### Canonical Endpoints (`/api/scm/*`)
- `GET    /api/scm/forecasts`: Retrieve active demand forecasts.
- `POST   /api/scm/forecasts`: Generate statistical forecast.
- `GET    /api/scm/mps`: Retrieve Master Production Schedules.
- `POST   /api/scm/mps`: Generate/update MPS schedule.
- `POST   /api/scm/mrp/run`: Execute Regenerative or Net-Change MRP netting.
- `GET    /api/scm/mrp/results`: Fetch computed net requirements and planned orders.
- `GET    /api/scm/mrp/exceptions`: Fetch active planning exceptions.
- `POST   /api/scm/mrp/exceptions/:id/resolve`: Resolve planning exception.
- `GET    /api/scm/mrp/runs`: List historical MRP execution runs.
- `GET    /api/scm/mrp/runs/:id`: Get single MRP run breakdown.
- `GET    /api/scm/mrp/pegging`: Query upstream sales order lineage for component demands.
- `GET    /api/scm/mrp/net-requirements`: Net requirements calculation breakdown.
- `GET    /api/scm/safety-stock/guard`: Lead time and safety stock guard evaluation.
- `POST   /api/scm/purchase-requisitions`: Create purchase requisition suggestion.
- `GET    /api/scm/purchase-requisitions`: List purchase requisitions.
- `POST   /api/scm/purchase-requisitions/:id/delegate-po`: Delegate PR to M08 Purchase Order Single Writer.
- `POST   /api/scm/mo-suggestions`: Delegate MO suggestion to M25 Manufacturing Order Single Writer.
- `POST   /api/scm/delegation/batch`: Atomically delegate multiple PRs and MOs.
- `POST   /api/scm/mrp/runs/:id/vault-dms`: Seal MRP run snapshot into M29 DMS with SHA-256 hash.

### Backward-Compatibility Aliases (`/api/supply-chain/*`)
- `GET    /api/supply-chain/plans`: Active supply plans.
- `GET    /api/supply-chain/forecasts`: Active demand forecasts.
- `POST   /api/supply-chain/calculate-mrp`: Triggers `/api/scm/mrp/run`.
